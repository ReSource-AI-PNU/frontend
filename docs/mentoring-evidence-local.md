# 멘토링·근거 표시 변경 (2026-11-21)

로컬 브랜치 `codex/mentoring-evidence-local-20261121`. 배포·push 없음.

후속 근거 강화: 승인 기록 없는 자동 인상·시범기간은 적용하지 않으며, 공통 등급은 검증된 기준이 없으면 보류한다. 실제 계정의 후보에 시연 업체가 섞이지 않는다. 에이전트 안내에 업무 지침의 출처와 NIST 참고 범위를 표시하고 근거 상세에 정책 승인 기록을 보여 준다. [후속 조사·실제 Azure 연결 결과](../../backend/docs/v3/agent-grounding-and-azure-2026-11-21.md).

후속 화면 검증은 기준표·합의·검수 단가 300원, 정정 중량920kg, 보고서/CSV 276,000원으로 통과했다. 단위261통과·3skip, 빌드/TypeScript·변경 파일 ESLint 통과. 화면 검증의 업체·문서는 명시적 가상 시험 입력이며, 실제 Azure 모델 연결 확인은 별도 수행했다.

관련 백엔드는 같은 상위 디렉터리의 `backend`다. 전체 가정 목록·원문 조사·채택 및 제외 사유·계산 경계·발표 답변은 [백엔드 조사 기록](../../backend/docs/v3/mentoring-evidence-2026-11-21.md), 실행 환경·테스트·재현 명령은 [검증 기록](../../backend/docs/v3/verification-2026-11-21.md)에 있다.

변경 화면:

- 업체 정보: 잘못된 단가 범위 저장 차단, 처리 기술 선언, 등록된 검수 대체 기준만 선택, 산업단지 거리의 한계 표시.
- 자료: 수율·신재 대체율·용도·접근 가능한 증빙·잔재 처리비 입력. 미입력 기존 처리비를 250원으로 채우지 않음.
- 에이전트 안내: 회사/업체 목표·근거·한도·담당자 확인·규칙 실행과 모델 역할 구분. 질문의 내부 필드명 제거, 답변 잠금 완화.
- 결과·근거 상세: 미확인 비용의 잠정 금액, 실측/공식/문헌/가정/정책/보류, 입력→계수→식→출처, 버전·경계·제외 조건. 정책 badge와 가정 표시 구분.
- 승인·검수·실적: 합의 단가 명칭, 허가 담당자 대조와 기관 인증 구분, KST 날짜, 탄소 ‘산정 보류’ 표시. 보고서·CSV는 같은 서버 실적을 사용.
- CI: 필요한 backend token이 없으면 E2E를 조용히 건너뛰고 성공 처리하지 않음. 스크린샷·녹화·trace 자동 수집 비활성화.

검증: 프로덕션 빌드/TypeScript, 변경 파일 ESLint, 단위261통과·3skip, 별도 두 계정 실제 Chrome UI 흐름 통과. `scripts/verify-mentoring-local.mjs`는 loopback 주소만 허용하며 가상 텍스트 문서를 사용한다. 운영 모델·실제 OCR·배포 E2E 통과를 뜻하지 않는다.
