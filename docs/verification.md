## 남은 확인과 제한

운영 Azure 환경·실제 업체 데이터·실제 모델의 판단은 검증하지 않았다. 범위를 좁히는 판단은 업체 담당자에게 맡기고, 단가 수락은 거래 확정과 분리했다. 추가 운행 비교는 앱 내 확정 방문을 같은 회차로 수거한다는 가정이다. 앱 밖 실제 노선과 외부 발송은 연결하지 않았다.
