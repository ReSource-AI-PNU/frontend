# 설문 후속 결정

| 결정 | 이유 | 남은 제한 |
|---|---|---|
| `단가·사전 문의` 화면에서 공개 범위와 거래별 제안을 구분한다 | 공개할 단가와 내부 협상 한도가 다르다 | 범위를 좁히는 판단은 업체 담당자가 확인한다 |
| 단일 제안은 재질·품질·운반 확인 후 상대가 수락한다 | 중간값이나 AI 추정값을 확정가로 만들지 않는다 | 실제 거래는 기존 찾기와 양쪽 승인 절차를 거친다 |
| 처음 등록할 때 모르는 값은 비워 둔다 | 기록이 없는 공장도 시작할 수 있어야 한다 | 재질·허가·품질이 확인되지 않으면 확정 매칭을 보장하지 않는다 |
| 계량 CSV와 품질 자료를 분리한다 | 보유 중인 계량 기록부터 쓸 수 있게 한다 | 같은 날짜·같은 무게의 별도 반입은 계량번호가 필요하다 |
| 사진은 기본 비공개이며 문의 상대를 직접 선택한다 | 수거 전 품질 확인과 공유 범위를 함께 관리한다 | 앱 밖 이메일 발송은 하지 않는다 |
| 추가 운행비는 업체에게만 보여 준다 | 배출 기업에 다른 고객 위치와 운행 원가가 노출되지 않게 한다 | 앱 내 확정 방문을 같은 회차로 수거한다는 가정이다 |

## AI 산출물에서 바로잡은 것

| 항목 | 수정 | 확인 |
|---|---|---|
| 저장 후 컴포넌트 재생성으로 안내가 사라짐 | 업체 ID를 기준으로 화면 상태를 유지 | 공개 범위 저장 브라우저 검사 |
| 계량 업로드 결과가 일반 저장 메시지로 덮임 | 신규·기등록 건수를 표시 | CSV 재업로드 브라우저 검사 |
| UTC 월말에 기본 합산 월이 하루 어긋날 수 있음 | 서울 시간대로 기본 월을 선택 | 월 경계 단위 검사 |
| 일반 AI 문의 상대가 사진 공유 목록에서 빠짐 | 기존 문의 상대도 선택 목록에 포함 | 백엔드 일반 문의 공유 검사 |
